تطبيق ويندوز لنظام محل الإكسسوارات
===================================

الطريقة (مرة واحدة على جهاز ويندوز عليه إنترنت):
1) نزّل وثبّت Node.js (نسخة LTS) من nodejs.org
2) فك الضغط عن المجلد، وافتح داخله CMD أو PowerShell
3) شغّل:
     npm install
     npm start          (لتجربة التطبيق قبل البناء)
     npm run dist       (لبناء ملف التثبيت)
4) هتلاقي ملف التثبيت (.exe) داخل مجلد dist. ثبّته على أي جهاز ويندوز.

ملاحظات:
- ويندوز ممكن يظهر تحذير SmartScreen لأن البرنامج غير موقّع. اختار "More info" ثم "Run anyway".
- البيانات بتتحفظ على الجهاز نفسه (في AppData). خد نسخة احتياطية من الإعدادات بشكل دوري.
- لنقل بياناتك من النسخة الأونلاين: من الإعدادات هناك اضغط "نسخة" وانسخ النص، وفي التطبيق اضغط "استرجاع" والصقه.
- لتغيير أيقونة البرنامج: ضع ملف build/icon.ico (256x256) وأعد تشغيل npm run dist.
